mosen717 客户登记系统

你只需要做一次上传：

1. 解压这个 ZIP。
2. 打开 GitHub 仓库 mosen717。
3. 选择 Add file → Upload files。
4. 把解压后的“所有文件和文件夹”一次性拖进去，包括 .github 文件夹。
5. 页面底部点击 Commit changes。
6. 上传完成后回到 ChatGPT 告诉我：上传好了。

不要修改任何文件内容。

部署成功后的目标地址：
管理员： https://mosen6266-netizen.github.io/mosen717/admin.html
业务员： https://mosen6266-netizen.github.io/mosen717/login.html
首页：   https://mosen6266-netizen.github.io/mosen717/

说明：
- 管理员登录后可以新增/停用/删除登记字段。
- 管理员可以创建业务员账号和初始密码。
- 业务员登录后只能操作自己的客户记录。
- 管理员可以查看全部客户并导出 CSV。
- 数据使用已建立的共享后台，不保存在 GitHub 文件中。
