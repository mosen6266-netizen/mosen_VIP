# mosen_VIP

融合版客户工作台。此仓库独立开发，不修改原来的 `mosen717` 与 `mosen6266` 仓库。

## 当前第一阶段

- 以 `mosen717` 客户登记系统为主体完整复制
- 保留原登录、管理员、业务员、客户列表、筛选、分页、客户资料与进度功能
- 复制 `mosen6266/data/chat-flows.json` 为本仓库独立流程快照
- 在业务员与管理员客户列表的每个客户旁加入“维权流程”按钮
- 每个客户分别保存每一句话术的“已发送”状态
- 自动显示当前流程完成比例与“下一句”
- “复制并勾选”会复制实际发送的德语/英语内容，同时标记该客户该步骤已发送
- 可手动取消勾选
- 流程中的附件与工具快捷方式在面板中保留

## 隔离原则

- 不向 `mosen717` 仓库写入任何代码
- 不向 `mosen6266` 仓库写入任何代码
- VIP 客户话术进度使用独立 localStorage 命名空间：`mosen_vip_customer_flow_v1:<customerId>`
- 当前客户登记数据仍使用原客户系统相同的 Base44 后端，因此两套客户页面看到的是同一批客户数据；VIP 新增的“维权流程勾选进度”不会写入 Base44，也不会影响旧页面

## 后续融合方向

后续可继续把打开器中的其他工具逐个复制到 `mosen_VIP/tools/`，然后把维权流程里的快捷方式改为优先打开 VIP 内部工具，从而逐步减少对原打开器仓库的依赖。
